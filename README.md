# 山猪 WoG 助手

《War of Genesis: Idle Loot》的中文本地助手 —— 加点、训练、装备、刷图、伤害、进度、宝玉、仓库、日常自动化，全在一个页面里，直连本机游戏读数据，不经过外网。

> **来源与声明**
> 界面与功能结构来自社区 wiki 的 [Companion 工具页](https://warofgenesis-idleloot.wiki/zh-cn/tools/companion/)（作者已**停止对新版游戏适配**）。本项目在原页面基础上接手继续适配新版，并补了自动化能力。**非官方项目，与游戏开发商、发行商无关。**
> 图鉴数值来自社区整理，个别条目可能和游戏内显示有出入，**以游戏内为准**。

## 两种用法

### 方式一：下载 exe（推荐，给不想装 Python 的人）

到 [Releases](../../releases) 下最新的 `WoG-Assistant.exe`，双击即可 —— 会起本地服务并自动打开浏览器。关掉黑窗口 = 停止服务。

首次运行 Windows 可能弹「已保护你的电脑」，点**更多信息 → 仍要运行**（exe 是用 PyInstaller 打包的，没有代码签名）。

### 方式二：源码跑

```bash
python start.py
```

只依赖 Python 标准库（3.9+），不用装任何包。

两种方式都一样：固定用 `127.0.0.1:8791`，重复双击不会开第二个服务，只会把已有页面再打开一次。

> 端口写死是故意的：页面设置存在 `localStorage`，而浏览器按「协议+主机+端口」隔离，端口一变设置就"丢"了。

## 连游戏之前

1. **先启动游戏**《War of Genesis: Idle Loot》，再打开助手
2. 游戏默认不开 `10998`（Puerts Inspector）端口，助手会检测并弹窗，点一次 **「⚡ 注入补丁」** 就好
3. 注入是**改进程内存里的端口号**（把 `-1` 改成 `10998`）：不写游戏文件、不改存档、关掉游戏自动恢复
4. 需要管理员权限时，以管理员身份运行

没有注入也能用：图鉴查询、伤害计算、加点规划、方案保存全部离线可用，只是读不到实时数据、写不进游戏。

## 关于网页版

这个仓库也放了纯静态页面，可以直接托管。但**托管版读不到你的游戏**：浏览器的私有网络访问（PNA）限制不允许 https 页面直连 `127.0.0.1` 的 WebSocket。

想用托管页面连游戏，需要本机跑一个转发端（连接器 exe）。页面里「本地版 / 连接器」那一行有下载入口和状态检测。**这一步目前还在做，托管版暂时只能当纯计算器用。**
